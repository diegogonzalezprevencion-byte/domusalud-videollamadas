# Domusalud Videollamadas

Aplicación inicial con Next.js, Supabase y LiveKit.

**Empieza por [`GUIA-INSTALACION.md`](GUIA-INSTALACION.md)**: explica cómo activar la base de datos, subir el código a GitHub y desplegar en Vercel sin programar.

Estado de V1: acceso, calendario, creación de reuniones, invitados registrados, video, minutas manuales. Grabación, IA y envío de correo pendientes de desarrollo.

Para desarrollo local (opcional): `npm install`, crear `.env.local` a partir de `.env.example` sin subirlo a GitHub y ejecutar `npm run dev`.
